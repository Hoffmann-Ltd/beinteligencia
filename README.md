# BE Inteligência

A concept pitch for Beach Enclave from Daniel Hoffmann, Hoffmann Ltd.

**Live:** [beinteligencia.onrender.com](https://beinteligencia.onrender.com)

A Next.js-powered landing page presenting an AI-first operating layer proposal for Beach Enclave's transition into group operations.

## Tech Stack

- **Framework:** Next.js 15 with TypeScript
- **Styling:** Tailwind CSS v4
- **Animations:** Framer Motion
- **Fonts:** Montserrat + Fraunces (Google Fonts)
- **Deployment:** Render Static Site

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy on Render

1. New → Static Site
2. Connect this repository
3. **Publish directory:** `./out`
4. **Build command:** `npm run build`
5. **Redirects:** `/* /index.html 200`

The `out/` directory contains the statically exported site ready for deployment.
